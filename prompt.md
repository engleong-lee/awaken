# 醒来 AWAKEN — Episode Generation Prompt

Use this prompt when generating new episode scripts. Paste it along with the episode's section outline.

---

```
You are writing a Chinese podcast monologue script for 醒来 (AWAKEN), a late-night companion podcast.

CRITICAL STYLE RULES — follow these exactly:

1. ONE CORE METAPHOR per episode. Introduce it early, then explore it through 3-4 specific real-life examples. Do NOT introduce new metaphors or concepts after the halfway point. EP05's "房客" (tenants) is the gold standard: one image, deeply explored.

2. PERSONAL FIRST-PERSON VULNERABILITY. The host shares their own experiences:
   - "我有过" (I've felt this)
   - "说出来有点不好意思" (a bit embarrassed to share this)
   - "我也不确定对不对" (I'm not sure if this is right)
   - Never lecture. Never teach from above. Always share from beside.

3. SPECIFIC, PAINFUL, RECOGNIZABLE SCENARIOS. Not "someone was sad." Instead: "That moment when you rewrite a text message 10 times before sending 3 words." The listener should think "这说的就是我" (this is literally describing me).

4. EMOTIONAL ARC: Discomfort → Deeper discomfort → Small light → Gentle landing (not fully resolved)
   - Start with a trigger everyone recognizes
   - Go DEEPER into why it hurts (childhood, identity, old wounds)
   - Don't rush to comfort. Let the listener sit in the discomfort
   - Offer a small, actionable insight (not a solution)
   - End with an open question, not a neat conclusion

5. NO CONCEPT SOUP. If you find yourself introducing a 3rd or 4th major idea, STOP. Cut it. One concept, deeply felt, is infinitely better than four concepts lightly touched.

6. KEEP IT CONVERSATIONAL. Use:
   - "你有没有过那种感觉？" (Have you ever felt that?)
   - [停顿] for breathing room
   - Short sentences. One idea per line.
   - Questions to the listener (not rhetorical — genuine)

7. WORD COUNT: 2800-3500 Chinese characters (~15-18 min). Do NOT exceed 3500. If the script runs long, cut subtopics rather than shortening each section.

8. THE LISTENER SHOULD CRY OR GET CHILLS, not nod along. Test each section: does this NAME something the listener feels but cannot articulate? If not, rewrite it.

9. END WITH A QUIET, INTIMATE QUESTION addressed directly to the listener's heart. Not a grand philosophical closing — a simple, personal question that lingers.

Structure:
- Opening hook (~1 min): A specific, relatable moment that immediately creates recognition — "被一句话刺到" level specificity
- Introduce the metaphor (~2 min): One clean image that will carry the entire episode  
- Explore through 3-4 examples (~8-10 min): Each example is a specific scenario → the metaphor applied → deeper wound revealed
- The shift (~2 min): A small reframe — not a solution, just a different angle
- Gentle landing (~2 min): Actionable micro-step + lingering question

Format: Include [停顿] marks (3-5 per episode), [IMAGE: description, 16:9] prompts after major sections. End with a 灵魂拷问 (soul question) section.

Now write the full monologue script for this episode:
[PASTE EPISODE STRUCTURE HERE]
```
